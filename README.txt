Sistema de Estoque (HTML + CSS + JavaScript)

Como usar: abra o arquivo login.html no navegador (duplo clique).
Não precisa instalar nada.

Usuários de teste: admin/admin123 e maria/maria123

Os dados ficam no localStorage do navegador, começando com o conteúdo do estoque.db.
Para voltar aos dados iniciais: abra o console (F12) e rode DB.restaurarDadosIniciais()

Arquivos:
  login.html / index.html (painel) / produtos.html (lista + CRUD)
  css/style.css
  js/db.js (dados e regras)  js/auth.js (login)  js/ui.js (funções comuns)
  js/login.js  js/painel.js  js/produtos.js
